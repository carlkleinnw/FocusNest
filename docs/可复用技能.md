## 已提炼的经验

- 自启动关闭与省电无限制可以同时存在。特定小米配置能避免进入强停分支，不能据此推广为抗真正强停。
- 原始设置、绑定、进程、FGS、覆盖焦点与实际拦截分别取证；unknown 保留未知。
- 开源 README、注释、不可达/被注释的函数均不充当已工作的实现；系统挂起可能在控制端死亡后仍持续，需要可靠释放路径。
- 必要设置页应验证实际跳转目标，新增必要包核对可信身份；普通 FLAG_SYSTEM 不作安全保证。
- 相同版本号不等于相同 APK；原签名环境、最终安装包与交付哈希分开核对。
- 手机测试操作串行，避免自己的导航打断遮挡测试；记录 UI 在后台与进程已死、跨升级恢复与新建会话的区别。
- 校验清单中的文件要实际随包/附件提供，下载复核后再确认远端交付。

## 复用方法

技能位于 `.agents/skills/`，每个目录自带 SKILL.md、可选参考资料与界面元数据；自动匹配元数据开启，也可显式写 `$技能名`。要复用到另一项目，将所需技能目录复制到其 `.agents/skills/`；在支持用户技能目录的客户端也可放入个人技能目录。实际发现以客户端加载结果为准。

本机的用户技能副本放在 `E:/CodexSkills/skills/`，由既有用户技能发现目录链接到 E 盘；旧的同名个人技能保留到 `E:/CodexSkills/backups/`。安装包只含技能、参考、只读脚本及样例测试，不含 APK、手机记录、第三方源码仓、凭据或签名文件。

只读脚本需要已有 Python 3 和 ADB，运行方式见技能中的 references/read-only-diagnostics.md；纯文档技能不需安装依赖。新增脚本以合成样例验证，整理技能本身不授权操作手机、授予新权限或对外发布。
