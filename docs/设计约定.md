# 伴学小屋 Demo 设计约定

0.2用于体验页面、宠物互动、计划联动与Android原生拦截。手机本机保存，网页虚拟模拟。正式发布前仍需多品牌真机验证。

## 页面职责

| 页面 | 唯一核心职责 |
| --- | --- |
| 小屋 | 和宠物互动 |
| 计划 | 创建、编辑与选择任务计划 |
| 长期目标 | 制定并查看长期目标 |
| 目标详情 | 拆分阶段与关联每日任务 |
| 专注 | 执行一次专注会话 |
| 记录 | 查看专注历史 |
| 休息 | 提前安排休息日期 |
| 应用 | 选择专注时允许的应用 |
| 领养 | 完成重启专注后领养 |
| 演示 | 控制虚拟时间和重置状态 |

## 代码与界面原则

1. Flutter负责页面，Flame只负责绘制和互动反馈。游戏帧率不驱动计时或饥饿规则。
2. Riverpod注入时钟、数据、设备和智能服务；业务操作集中到控制器。
3. 模型不可变；Widget发送操作，读取状态，不直接改宠物生命值。
4. 页面布局、按钮、面板、任务卡片、状态标签、空状态与宠物绘制均为可复用组件。
5. 宽屏侧边导航，窄屏底部导航与更多菜单；内容有最大宽度。
6. 每页一个主要动作。用位置、文案、形状和颜色共同表达状态。
7. 自定义场景提供对应的可访问按钮；确认框支持键盘和取消。
8. 网页是内存数据，刷新重置；手机使用私有SQLite保存。时间快进仅在网页提供，不算真实学习。

## 已确认与暂定规则

- 单次至少30分钟，完整完成设定时长后自动喂食；取消会话无奖励。
- 提前退出恰好两轮确认。手机的默认拨号器、系统电话与必要组件始终允许，打电话不需要退出专注。
- 7个连续非休息日未完成专注会死亡。休息日只能提前安排，过去与当天不可补改。
- 暂定：完成一次专注将饥饿计数清零；同一天多次完成不储备未来食物。
- 死亡后，完整完成一次至少30分钟的重启专注才能领养，新宠自动获得首次喂食。
- 专注中宠物静卧、互动禁用；互动不会喂食。
- 内部与悬浮预览共享宠物状态。网页内悬浮仅为模拟，不显示在真实其他应用上方。
- 第一版不接大模型与Agent。仅有明确类型的扩展接口及禁用实现。
