# 伴学小屋 Demo 设计约定

> **0.3.0 当前约定（2026-10-16）：** 用户已授权接入 DeepSeek，主流程收敛为今日计划、AI规划、沉浸专注、复盘，设置独立。本文下方的0.2内容作为历史机制说明；其中“AI仅预留/禁用”“宠物阻止专注”“未完成任务待手动调整”等旧产品边界不再适用。以[核心功能重构](核心功能重构.md)和当前源码为准。

## 0.4.8 信息架构（2026-10-18，当前）

- 核心功能决定主入口：日程、AI、沉浸三项，第四项为「我的」。
- 「我的」承载复盘、长期目标、专注保护与设置；进入这些子页时隐藏底部导航并显示返回。
- 日程以今天为中心：周日期条 + 时间列任务列表 + 一行进度摘要；周/月/季/总目标收进标题旁「视图」底部弹层。
- 页面标题与叫法对齐核心：日程、AI Agent、沉浸模式。

## 0.4.7 导航（2026-10-18，上一版）

- 主导航固定五项：计划、AI 规划、沉浸专注、复盘、设置；标题栏不再放设置入口。
- 手机使用平铺底部 Tab，宽屏使用左侧栏；设置作为一级页保留导航，专注保护、长期目标、目标详情等子页隐藏导航并显示返回。

## 0.4.6 清晰度修订（2026-10-18，上一版）

在 0.4.5 的微信式排版与小米配色上，只调整对比与层级：

- 画布加深为 `#F1F2F5`，分组纯白；分割线 `#E6E8EC`；正文 `#151619`、次级 `#6F747C`、三级 `#9CA1A9`。
- 页面标题 24/600；分组标题、任务标题、设置项标题 16/500；辅助文字 13；筛选 Tab 15（选中 600 + 橙色下划线）。
- 选中态：日期浅橙圆底、时长选项浅橙底加橙描边、输入框描边 `#DCE0E6`；搜索框与筛选按钮补边框。
- 指标数字与今日完成数加大，保证白卡与灰底之间、主次文字之间的边界一眼可辨。

## 0.4.5 界面语言（2026-10-18，上一版）

排版参考微信的克制结构，配色使用小米风格：灰色画布、纯白列表分组、1px 细分割线、近黑正文，小米橙 `#FF6900` 作为行动与选中色，绿色只表示完成。不使用渐变、深色大卡、进度环、彩色图标块、悬浮导航和阴影。

**页面与结构**

| 页面 | 唯一核心职责 | 主要结构 |
| --- | --- | --- |
| 计划 | 按层级查看与维护任务 | 白色概览行 + 文字层级 Tab + 周日期条 + 搜索 + 单一任务列表 |
| AI 规划 | 把目标变成可执行安排 | 引导分组 + 微信式气泡 + 草稿 + 输入区 |
| 沉浸专注 | 执行一次专注 | 大号计时 + 描边时长选项；进行中为白底计时与 3px 进度线 |
| 复盘 | 查看统计与压缩复盘 | 2×2 指标 + 文字筛选 + 复盘分组 + 明细列表 |
| 设置 | 管理密钥、规则与保护 | 分组列表：AI 助手 / 计划与复盘 / 专注保护 / 关于 |
| 专注保护 | 管理白名单与系统权限 | 白名单分组 + 保护状态 + 后台稳定性 |

**设计令牌（`lib/ui/theme.dart`）**

- 画布 `#F4F5F7`，分组 `#FFFFFF`，分割线 `#EDEEF2`，正文 `#17181A`，次级 `#8A8E96`，三级 `#B9BDC5`。
- 行动/选中为小米橙 `#FF6900`（浅底 `#FFF1E6`，深字 `#E85A00`），完成用小米绿 `#0F9D58`，信息蓝 `#2F7CF6`，错误 `#E5484D`，提醒 `#C77700`。
- 圆角：分组 8，弹层 12，按钮/标签 4–6；不使用阴影。
- 字号：页面标题 22/600，分组标题 16，正文 15，辅助 13，脚注 12；导航标题 17/600。
- 字体：小米设备使用系统 MiSans；其余平台回退系统中文；网页使用浏览器默认中文字体。

**组件（`lib/ui/components.dart`）**

`PageFrame`、`SurfacePanel`（白色分组）、`SettingsGroup`/`SettingsRow`（带 16 缩进分割线）、`PillTabs`（文字 Tab + 绿色下划线，底层仍为 `ChoiceChip`）、`MetricTile`、`StatBlock`、`StatusPill`、`TagLabel`、`MetaText`、`MainButton`、`EmptyPanel`。

**布局与可访问性**

- 手机：白色居中导航栏 + 平铺底部 4 Tab；详情页隐藏 Tab、左上返回。宽度 ≥900 改为左侧栏。
- 主内容最大宽度 860；手机左右留白 16，桌面 24。
- 保留测试依赖的控件类型、Key 与文案；文本缩放 1.3 时不得溢出；状态不只靠颜色表达。

## 0.4.4 界面语言（2026-10-18，上一版）

参考小米 HyperOS 系统应用的视觉语言重做主流程界面：近白画布、纯白卡片、大字号标题、克制的暖橙强调色，阴影只用于浮层与主卡片。旧版“纸张+墨绿”的学舍风格不再用于主流程页面。

**页面与结构**

| 页面 | 唯一核心职责 | 主要结构 |
| --- | --- | --- |
| 计划表 | 按层级查看与维护任务 | 今日概览（深色渐变+进度环）、层级分段、周日期条、任务行 |
| AI 规划 | 把目标变成可执行安排 | 引导卡、对话气泡、草稿预览、底部输入区 |
| 沉浸专注 | 执行一次专注 | 时长圆盘+开始；进行中为深色计时卡与进度条 |
| 复盘 | 查看统计数据与压缩复盘 | 2×2 指标卡、周期筛选、复盘卡、明细分组 |
| 设置 | 管理密钥、规则与保护 | 资料卡、AI 助手、计划与复盘、专注保护、关于 |
| 专注保护 | 管理白名单与系统权限 | 白名单列表、保护状态、后台稳定性说明 |

**设计令牌（`lib/ui/theme.dart`）**

- 画布 `#F4F5F7`，卡片 `#FFFFFF`，发丝线 `#EDEEF2`，正文墨色 `#17181A`，次级文字 `#8A8E96`。
- 强调色为小米橙 `#FF6900`，只用于主行动、选中态和进度；绿色 `#0F9D58` 表示完成，蓝色 `#2F7CF6` 表示信息，红色表示失败。
- 圆角：卡片 22，弹层 28，图标底 12，按钮与标签为胶囊。
- 字号：页面标题 28/700，区块标题 22/700，正文 14–15，辅助 12；数字使用等宽数字。
- 字体：小米设备使用系统 MiSans；其他平台回退到苹方/思源黑体/微软雅黑。网页端使用浏览器默认中文字体，避免网页端缺少指定字族时中文字宽测量不一致。

**组件（`lib/ui/components.dart`）**

`PageFrame`（页头+最大宽度+底部浮层留白）、`SurfacePanel`（白卡）、`PillTabs`（分段控件，底层仍是 `ChoiceChip` 以保留测试与选中语义）、`ProgressRing`、`MetricTile`、`SettingsGroup`/`SettingsRow`、`IconBadge`、`TagLabel`、`MetaText`、`StatusPill`、`MainButton`、`EmptyPanel`。新增界面优先复用这些组件，不在页面内重复定义卡片与按钮样式。

**布局与可访问性**

- 手机：页头 + 内容 + 悬浮底部导航（4 项）；宽度 ≥900 时改为左侧栏。
- 主内容最大宽度 1080，正文最大宽度 680；手机左右留白 20，桌面 36。
- 保留既有测试依赖的控件类型、Key 与文案；分段控件在手机使用“日／周／月／季／目标”短标签。
- 文本缩放 1.3 时页面不得溢出；状态同时用颜色、图标和文案表达，不单靠颜色。

0.2用于体验页面、宠物互动、计划联动与Android原生拦截。手机本机保存，网页虚拟模拟。正式发布前仍需多品牌真机验证。

## 代码与界面原则

1. Flutter负责页面，Flame只负责绘制和互动反馈。游戏帧率不驱动计时或饥饿规则。
2. Riverpod注入时钟、数据、设备和智能服务；业务操作集中到控制器。
3. 模型不可变；Widget发送操作，读取状态，不直接改宠物生命值。
4. 页面布局、按钮、面板、任务卡片、状态标签、空状态与宠物绘制均为可复用组件。
5. 宽屏侧边导航，窄屏底部导航与更多菜单；内容有最大宽度。
6. 每页一个主要动作。用位置、文案、形状和颜色共同表达状态。
7. 自定义场景提供对应的可访问按钮；确认框支持键盘和取消。
8. 网页是内存数据，刷新重置；手机使用私有SQLite保存。时间快进仅在网页提供，不算真实学习。

## 已确认与暂定规则

- 单次至少30分钟，完整完成设定时长后自动喂食；取消会话无奖励。
- 提前退出恰好两轮确认。手机的默认拨号器、系统电话与必要组件始终允许，打电话不需要退出专注。
- 7个连续非休息日未完成专注会死亡。休息日只能提前安排，过去与当天不可补改。
- 暂定：完成一次专注将饥饿计数清零；同一天多次完成不储备未来食物。
- 死亡后，完整完成一次至少30分钟的重启专注才能领养，新宠自动获得首次喂食。
- 专注中宠物静卧、互动禁用；互动不会喂食。
- 内部与悬浮预览共享宠物状态。网页内悬浮仅为模拟，不显示在真实其他应用上方。
- 第一版不接大模型与Agent。仅有明确类型的扩展接口及禁用实现。
