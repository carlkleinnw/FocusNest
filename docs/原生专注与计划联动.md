# 0.2 原生专注与计划联动

## 体验方式

Android使用真实时钟和本机SQLite；网页保留虚拟时间、模拟应用列表和刷新重置。初始学习计划、历史与宠物仍为演示样例，真实新增记录另行保存。

手机进入「更多 → 应用锁定 → 前往系统开启权限」，在无障碍设置找到「伴学小屋专注保护」。权限由用户本人开启。页面显示「保护权限已开启」后才能开始原生专注。

读取可启动应用列表，默认建议允许非娱乐应用、限制游戏/视频/音乐及少量已知娱乐应用。分类可能不完整，用户应确认开关；开启表示加入白名单。原生服务在开始时保存明确的白名单，白名单之外的应用均限制，包含专注中新安装且未允许的应用。电话、默认拨号器、桌面、设置和系统必要组件始终允许。厂商承载权限/省电设置的应用通过系统意图解析加入必要名单。专注期间名单不能修改。

打开未允许的应用时，原生服务显示全屏提醒，遮住应用内容；点击「知道了」请求返回桌面。提醒不会自动关闭，快速重复打开仍会重新拦截。系统接受HOME请求与桌面真的出现分开记录；仅核实允许应用/桌面在前台或到期才撤提醒。普通Android应用不结束其他应用进程。识别在应用切换后异步执行，不能保证零毫秒拦截。

提醒页采用与Flutter相同的米白、绿色、浅绿和圆角面板。全屏覆盖包含刘海区域；布局变化后按可用高度重新排版，小屏可滚动，避免游戏突然横屏时裁掉按钮。

无障碍服务订阅窗口状态/窗口列表变化；通知只作为检查触发器，不把任意通知来源当作前台。使用getWindows提供的应用窗口层级和根窗口packageName识别当前应用，忽略键盘、系统窗口与自己的覆盖层。横屏切换时焦点标记可能暂未更新，识别仍使用可见应用窗口的层级。识别不到时保留已显示的提醒，不因未知窗口撤掉。Android33+定期刷新窗口缓存。

系统要求声明窗口内容访问能力和交互窗口标记，不能再声称「未授予窗口访问能力」。实现只取根窗口的应用标识，不遍历节点，不读取文字、输入内容、内容描述或截图；应用名单和根节点均不上传。非必要窗口元数据不持久保存。加入非重要视图事件标记以覆盖游戏等缺少普通无障碍视图的界面。

专注期间以前台服务运行，提供低优先级保护通知；Android34+声明specialUse类型及用途，结束/取消后移除通知并停止前台运行。仅此配置不能抵抗全部厂商策略：本次小米15真机在「智能限制后台运行」下出现检查暂停，改为伴学小屋「无限制」后再验证。应用锁定页提供本人应用信息入口，引导检查省电策略。若系统已关闭通知，通知栏可能隐藏通知，Android仍会在运行应用管理中展示前台服务。

应用锁定页显示服务连接/窗口访问、规则启用、受限数量、后台运行、窗口检查、提醒真实获得焦点次数和返回桌面核实结果。尝试addView与实际获得窗口焦点分开计数。复制诊断采用字段白名单，不含安装应用名单、前台包名、任务标题或页面内容；计数仅本机运行期保存。覆盖安装后需检查实际服务连接，系统保留授权开关不代表新服务已经连接。

0.2.2的连接状态依据系统返回的服务信息，旧实例结束时不会清除新实例。数据库在服务创建时初始化，避免事件处理依赖连接回调顺序。诊断复制采用字段白名单，不包含应用名单、任务标题或用户页面内容。

原生状态机回归检查可运行android/check-focus-gate.ps1，传入已有JDK的JavaHome；无新增测试依赖。覆盖未知窗口保持、层级识别、横屏未稳定焦点、确认请求、HOME接受但未见桌面时继续遮挡、快速重开、白名单外新应用、必要电话与到期放行。该检查不能替代Android真机验证。真机流程检查用ADB观察窗口焦点、拍摄自己的提醒并点击按钮，避免UIAutomator临时暂停其他无障碍服务影响测试。

普通提前退出和安卓系统返回键共用两轮确认。返回桌面并不取消专注。退出与会话结果一起落盘，避免中断后把取消的专注误算为完成。

## 计划联动

长期目标记录总量、单位、截止日期；阶段记录分量和阶段期限。每日计划选择目标与阶段、日期、计划时间、数量和专注时长。总安排不能超过目标或阶段数量，日期不能超过对应期限，每日时长不能超过可用时间。

用户手动记录每日任务的实际完成数量；同一任务修改进度采用覆盖，重复保存不重复累计。长期目标与阶段按任务完成量动态汇总。计时完成不直接认定任务完成；手动勾进度不会喂食。

未完成的过去任务进入「待调整」，用户决定如何重新安排。不会自动覆盖原计划或无限堆积到明天。计划时间目前只供安排参考，没有后台通知或定时自动开始。

## 存储与恢复

数据在应用私有SQLite内保存，保存失败展示提示，加载失败保留已有数据并提供重试。启动后按保存日期补算未喂食天数与休息日，先结算此前已到时的专注，再推进下一天。

原生专注规则与开始/完成/取消状态使用同一个SQLite事务保存。前端保存队列按顺序写入；会话操作先等待队列，防止旧快照覆盖新会话。到时后服务独立放行，打开应用后补计记录与喂食。

普通计划编辑仍异步落盘；未完成保存时突然断电可能丢失最后一次修改。当前不是经过长期运行验证的正式版本。

## 当前边界

- 仅实现Android；网页不会拦截真实手机应用。没有iOS原生限制。
- 不能阻止用户关闭无障碍权限、强行停止、卸载或修改系统时间。
- 未实现设备所有者/kiosk、系统级禁止安装、阻止卸载或娱乐应用强制停止。
- 服务被系统或厂商后台策略停用会失去保护；UI在运行时检查权限。不同品牌需要分别真机验证。
- 应用分类是建议，不能保证自动识别所有娱乐软件，也不能区分同一应用中的课程和娱乐。
- 外部悬浮宠物仍未实现；小屋与应用内悬浮预览可互动。
- 智能接口保留，大模型与Agent未启用，无模型密钥和自动建议执行。
