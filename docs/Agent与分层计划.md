# 0.4 Agent 与分层计划

2026-10-17，用户要求 AI 理解原始目标与后续补充，自行判断是否追问，并能直接管理计划。此前“固定澄清 → 草稿 → 导入”的能力扩展为可读写计划的 Agent；Flutter、Riverpod、SQLite 和原生专注服务继续复用。

## 决策与执行

参考 [Anthropic：Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) 中模型动态选择工具、读取环境反馈、清晰工具契约和有限迭代的原则。本项目使用现有 DeepSeek JSON 通道承载工具协议，不新增大型 Agent 框架。

1. 每次请求包含完整保留的用户／助手对话、当前未保存草稿，以及计划目录和真实 ID。目录明确各类总数及是否截断（最多50个目标、80个周期、80个任务）；模型可用分页查询按需取详情，每页最多200项，不将预览误作全部数据。并发修订检查始终使用完整数据。后补要求覆盖冲突的旧要求，保留其他条件。
2. 模型决定返回问题、草稿、工具调用或普通答复。信息足够即行动；仅在实质性缺失或指代歧义时询问。连续追问最多3轮；回答／成功操作后重置。对话不再限制为原先的5次发送，累计内容过长时明确提示新建对话，不静默丢掉最初需求。
3. 工具支持 `goal`、`period`、`task` 三类实体的 `query/create/update/delete`；另有 `create_plan` 一次创建完整分层安排，和确认草稿共用同一执行器。查询可以按 ID、所属目标、层级、日期区间、关键词与完成状态过滤。模型读取真实查询结果后继续选工具；不会按关键词硬编码用户意图。
4. 每次发送最多5步工具调用及一次最终答复。每批最多500个操作；校验日期、标题、时长、容量、真实 ID、关联目标及旧阶段约束。一天的容量在批次最终状态检查，支持同时移动与补充任务；同名同日同时间的重复创建会被拒绝。
5. 操作先在不可变副本暂存。任何一步校验失败，整次请求的暂存修改回滚，并将错误与回滚事实交给模型纠正；网络失败、迭代耗尽或最终结果无效均不保存部分修改。请求期间其他编辑改变了计划，拒绝过期写入。
6. 最终操作与对话结果一起等待 SQLite 写入成功。程序生成实际新增／修改／删除数量的收据；模型自由答复不作为落盘证明。界面显示查询、核对或纠错进度，不展示内部推理。

模型只能操作计划，不获得密钥读取、任意文件、权限、系统时间或专注会话工具。计时不会自动勾选任务，AI 也不能写入 `doneUnits/completedAt`。密钥继续仅由设置页的显式显隐能力读取，不进入对话或快照。

新目标默认可先预览草稿；用户明确要求直接保存时，模型使用工具创建总目标、季度／月／周成果与每日任务。对已保存计划的明确增删改请求直接操作，不再只给一段建议。

## 层级与兼容

计划页分为日、周、月、季度、总目标五个视图；每次展示一个层级，周期的每日任务默认折叠。支持日期切换、全部周期、目标筛选与关键词查询。各层均可新增、编辑、删除；每日任务继续支持勾选进度和进入沉浸。

总目标复用 `Goal`，日任务复用 `Plan`，周期成果由 `PeriodPlan` 投影到原有 `Workspace.roadmaps` 的 `weeks/months/quarters`。不引入第二套任务数据库，也不把每日任务复制到路线中。旧月／周数据获得稳定 ID；旧路线按月成果合并出可编辑的季度概览，首次修改后规范化保存；已删除的季度不会在重开后重新生成。快照仍为3，继续兼容2。

- 周成果区间最多7天；月／季度成果位于同一自然月／季度。
- 删除周期成果保留每日任务；改周期标题或日期不会暗中移动任务。整体调整时 AI 需显式操作涉及的各层。
- 删除总目标默认移除其周期成果，保留每日任务为独立任务；明确选择连同未完成任务删除时才清理待办，已有完成事实和计时记录保留。
- 专注期间不能修改计划。顺延、复盘压缩、白名单与原生到期机制继续沿用。

工具契约和纯事务执行器位于 `lib/core/plan_management.dart`，循环位于 `AppController.askPlanner`，模型边界仍为 `PlannerGateway`；页面仅发起业务操作。示例模式仍明确标注为固定样例，不作为真实 Agent 验证，也不在联网失败后自动冒充成功。

## 验证与适用范围

本轮验证记录见 `docs/validation/0.4.0-checks.json`。模拟器使用人工构造的目标、任务与真实 DeepSeek 接口，密钥、设备数据库、对话截图和临时日志均不进入 Git。发布前另装最终 APK 验证页面、存储及本轮核心流程；之前版本的完整30分钟后台保护证据不能冒称本版重新完成了完整时长测试。

模型仍可能误解自然语言；参数正确不等于语义永远正确。通过语义样例、真实查询反馈、歧义澄清和程序校验降低风险，不宣称任意指令均已穷尽测试。回退代码与应用版本不会恢复用户主动删除或已经压缩的明细，覆盖安装前必须核对原签名，不能卸载／清数据绕过。
