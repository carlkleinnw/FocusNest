# 伴学小屋：按本轮证据交付

以当前工作树、项目 AGENTS.md、当次用户指示及实际设备状态为准。历史交接用于选择检查项，历史阶段规则由当前项目文档确认，技能不冻结某个旧版本的功能开关。

## 按改动选择检查

- **原生保护故障**：使用 `android-accessibility-focus-debugging`；开源方案核对使用 `android-protection-source-audit`。覆盖提醒、持续遮挡、知道了返回桌面、重复打开、横竖屏、必要应用与到期/退出按项目要求验收，厂商条件重新取证。
- **模拟器上的 AI、页面或持久化流程**：读取[模拟器测试环境与驱动](references/emulator-runtime.md)，先确认实际安装包的配置、输入和页面准备状态。未改原生保护时，不自动扩展为完整长时保护验收。
- **APK、签名或发布附件**：读取[APK 与版本交付](references/apk-and-release.md)，核对最终安装的同一包与交付文件。
- **完整计时、长锁屏或恢复结算**：读取[稳定性证据与扩展边界](references/stability-evidence.md)。

按实际分支加载参考，不因使用此技能就读取全部资料。设备 UI 操作串行；正在由用户使用的手机与专注不作为可清理测试环境。

## 验收与完成

记录本轮最终包、较早候选、沿用历史证据与未验证范围。模拟器通过不扩大为个人手机或其他品牌通过；恢复旧会话与最终包独立跑完分开报告。核心流程未通过时保留候选状态。

当前授权范围内的验证完成后，按项目规则提交与新增附注标签；推送、发布沿用当次授权，技能不额外授予权限。分别说明提交、标签、远端分支、默认分支是否包含修改，以及附件实际交付状态。应用版本、签名、数据和隐私规则由对应项目文档及发布参考维护，避免在多个入口重复。
