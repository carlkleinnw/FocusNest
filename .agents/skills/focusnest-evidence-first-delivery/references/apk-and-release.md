# APK、签名和发布复核

## 沿用原签名与缓存

安装/新增工具前先看磁盘空间，确认可用的非 C 盘位置，优先使用已有工具。本机历史工具在 D 盘、缓存在 E 盘，未来路径要重查，不盲目重装。

2026-10-15 本机有效构建环境为：

```powershell
$env:PUB_CACHE = 'E:/DeveloperCache/focus_pet/pub'
$env:GRADLE_USER_HOME = 'E:/DeveloperCache/focus_pet/gradle'
$env:ANDROID_USER_HOME = 'E:/DeveloperCache/focus_pet/android'
$env:JAVA_HOME = 'D:/Android/Android_studio/jbr'
```

这些是本机历史配置，不是跨机器通用默认。遗漏 ANDROID_USER_HOME 曾让构建使用另一份 debug keystore；版本更高也会被 Android 拒绝覆盖。实际安装前用 SDK 的 apksigner 核对现有包与新包的证书 SHA-256，签名相同才 `adb install -r`，失败时保留原安装与数据。

本地 APK 的哈希、安装版本相同均不足以独立证明同包。需要时只拉取本应用安装 APK 到私有临时目录，与交付 APK 比较 SHA-256；无需导出数据库、其他应用或完整手机备份。私钥从不复制进技能、仓库或 ZIP。

## 证据矩阵

| 项目 | 记录方式 |
| --- | --- |
| 候选包与最终包 | 分别记录构建号、文件哈希、已安装版本与对应场景 |
| 权限与厂商条件 | 无障碍启用/绑定、可见自启动/省电设置；unknown 保留未知 |
| 划除 | 操作前后新退出时间、reason/subreason、stopped、重新绑定及实际拦截 |
| 覆盖与返回 | 持续遮挡、点击确认后真实桌面、同应用重复打开、横竖屏 |
| 必要应用 | 实际打开设置/省电/拨号器，核实跳转后的包而非只检查 resolveActivity |
| 会话与数据 | 原用户会话保留；新测试/跨升级恢复/自然到期/两轮退出分别标识 |
| 未验证范围 | 其他品牌、重启、清空所有任务、长期耗电按实际列出 |

UI 操作上一段未完成时，不并行导航。测试中转到设置会使“提醒持续遮挡”断言失效，应标为受干扰尝试并重跑。UIAutomator 可能暂停其他无障碍；普通 ADB 打开已有任务可能停留在设置子页，核对实际前台，必要时显式目标主 Activity + CLEAR_TOP。观测焦点和 ADB 耗时，不采集第三方页面正文。

## 版本与附件

具体脚本和标签规则以当前项目 AGENTS.md 与 scripts/Publish-Version.ps1 为准。本项目历史要求每轮完成更新有新附注标签，文档修订也一样；已发布标签不移动、不覆盖，安装新 APK 递增构建号。

先完成对应范围检查，再提交、标签并在已有授权范围内推送。仅技能/文档修改不要求重建 App；新增诊断脚本要以隔离样例验证其解析、失败分支与隐私输出。

打包后逐项确认：源码排除构建与私密运行数据；APK/网页为附件；校验清单覆盖的每个文件确实随包或附件交付；参考资料随技能携带，避免依赖不可访问的私有仓。发布后确认分支与附注标签解析到目标提交，下载附件复核哈希后再说远端交付完成。
